// ─────────────────────────────────────────────────────────────
//  HOW TO ADD A NEW ABAYA IMAGE
// ─────────────────────────────────────────────────────────────
//  1. Copy your photo file into this folder:
//       src/assets/images/abayas/
//
//  2. Use a clear file name, e.g.:
//       royal_gold_zari.jpg
//       emerald_velvet_abaya.png
//       bridal_ivory_kaftan.jpg
//
//  3. Open  src/assets/catalog/products.js
//     and add a new import at the top, then a new entry in the
//     PRODUCTS array.
//
//  Supported formats: .jpg  .jpeg  .png  .webp  .avif
// ─────────────────────────────────────────────────────────────
//  NAMING CONVENTION:
//    <color>_<fabric/style>_<type>.ext
//    Examples:
//      black_silk_open.jpg
//      champagne_satin_abaya.png
//      ivory_pearl_kaftan.webp
// ─────────────────────────────────────────────────────────────
